# 框架思路

这里按日期记录 AstraFramework 的设计想法。后续有新想法就接着写。某个想法形成具体方案后，再从对应条目链接到设计文档。

## 2026-11-19 · 为什么做这个框架

我想亲手做一套自己用得顺手的 Unity 框架，也借这个过程为以后做主程做准备。市面上的成熟框架和我在实际项目里使用框架的经验，都是参考。遇到具体问题时，我想看看各家怎么解决、为什么这么设计，再决定哪些做法适合自己的项目，哪些需要调整。

AI 也是这个项目的一部分。随着开发推进，我想把反复用到的工作方法整理成项目专用 skill，并给每个 skill 配上相应的文档。先从实际用到的一件事做起，逐步积累。
